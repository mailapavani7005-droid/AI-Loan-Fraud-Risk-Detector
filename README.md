# AI Loan Fraud Risk Detector
## Live Demo

[Open AI Loan Fraud Risk Detector](https://ai-loan-fraud-risk-detector-7gped8a9xmgjexkcejjgxo.streamlit.app/)

## Project Overview
This project helps banks and financial institutions identify risky loan applicants using AI-based risk assessment.

## Problem Statement
Banks receive many loan applications daily. Manual verification is time-consuming and may miss high-risk applicants.

## Solution
The system analyzes applicant details such as income, credit score and loan amount to classify applicants into:
- Low Risk
- Medium Risk
- High Risk

## Features
- Risk Assessment
- Fraud Detection Support
- Fast Decision Making
- User Friendly Interface
